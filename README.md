# Naji TV — مشغّل IPTV للويب والتلفزيون

تطبيق ويب واحد (HTML5) يشتغل على:

- 🌐 **المتصفح / PWA** — أي جهاز
- 📺 **Vidaa** (تلفزيونات Hisense) — عبر المتصفح المدمج أو كتطبيق رسمي
- 📺 **webOS** (تلفزيونات LG)
- 📱 قابل للتغليف لاحقاً لأي منصة ويب

المصدر واحد، بلا إعادة كتابة لكل منصة — لأن Vidaa و webOS كلاهما يشغّل تطبيقات الويب.

---

## الملفات

| الملف | الوظيفة |
|------|---------|
| `index.html` | الواجهة |
| `css/style.css` | التصميم (مهيّأ لشاشة 1280×720) |
| `js/app.js` | المنطق: تحميل M3U + تشغيل HLS + تحكم بالريموت |
| `js/hls.min.js` | مشغّل HLS (للأجهزة اللي ما تدعم HLS أصلياً) |
| `playlist.m3u` | **ضع قنواتك هنا** |
| `manifest.json` | إعدادات PWA |
| `appinfo.json` | إعدادات تطبيق webOS |

---

## ① ضع قنواتك

عدّل `playlist.m3u` بصيغة M3U القياسية:

```m3u
#EXTM3U
#EXTINF:-1 tvg-name="MBC" tvg-logo="https://.../mbc.png" group-title="عربي",MBC 1
http://your-server/mbc1.m3u8
```

- `group-title` = التصنيف (يظهر في الشريط الجانبي)
- `tvg-logo` = شعار القناة (اختياري)
- الرابط بعد كل سطر `#EXTINF` = رابط البث (HLS `.m3u8` أو MP4)

> لو ما فيه `playlist.m3u`، يعرض التطبيق قنوات تجريبية مفتوحة.

## ② جرّبه محلياً

```bash
# أي خادم ويب بسيط
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

**التحكم بالريموت / لوحة المفاتيح:**

| المفتاح | الوظيفة |
|--------|---------|
| ↑ / ↓ | تنقّل بين التصنيفات/القنوات |
| OK (Enter) | تشغيل القناة |
| Back / Return | رجوع |
| ← / → | تنقّل بين الأعمدة |

## ③ التشغيل على Vidaa (حسب قيودك)

### الطريقة أ — المتصفح المدمج (فورية، بدون موافقات)
1. ارفع مجلد المشروع على أي استضافة تدعم **HTTPS** (Netlify / Vercel / GitHub Pages / سيرفرك).
2. على التلفزيون: افتح **متصفح Vidaa** → أدخل الرابط → احفظه **Bookmark**.
3. يشتغل فوراً. ✅

> ⚠️ **قيد Vidaa:** لا يمكن تثبيت موقع عشوائي كأيقونة على الصفحة الرئيسية بدون المرور على المتجر الرسمي.

### الطريقة ب — تطبيق Vidaa رسمي (أيقونة على الصفحة الرئيسية)
1. سجّل في **VIDAA App Developer / Partner Program**.
2. ارفع نفس ملفات هذا المشروع (تطبيق HTML5) عبر بوابتهم.
3. بعد الاعتماد، يظهر التطبيق على الصفحة الرئيسية.

> هذا الطريق يتطلب موافقة/شراكة — لكن **الكود جاهز 100%** بلا تعديل.

## ④ التشغيل على webOS (LG)

المشروع فيه `appinfo.json` جاهز:

```bash
# بأدوات LG (ares-cli)
ares-package .
ares-install ./com.naji.tv_1.0.0_all.ipk
ares-launch com.naji.tv
```

## ملاحظات تقنية

- التلفزيونات (Vidaa/webOS) غالباً تشغّل **HLS و MP4 أصلياً** عبر `<video>`؛ ملف `hls.min.js` احتياطي للمتصفحات اللي ما تدعم HLS.
- الواجهة **RTL** وعربية بالكامل.
- التصميم على شاشة مرجعية 1280×720 (قياس شائع لتطبيقات التلفزيون) ويتكيّف.
