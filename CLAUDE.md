# Working agreements

- Ask before any large change. For a new feature or a multi-file edit, confirm the plan first.
- Build only what was asked. No speculative abstractions, options, or extra files.
- Reuse existing code and the standard library before adding new code or dependencies.
- Keep diffs surgical. Change only the lines the task needs.
- Verify before claiming done: run the relevant checks and report the actual output.
